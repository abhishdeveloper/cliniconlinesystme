## 2024-05-24 - N+1 Query and I/O Overhead in Batch Insertion
**Learning:** During the batch generation of appointment slots in `doctor/schedule.php`, the original code performed a `SELECT` statement to check for existing slots followed by an `INSERT` statement within a heavily nested loop (iterating through next 30 days and overlapping templates). This architecture-specific bottleneck causes major I/O overhead (N+1 database reads and writes) which degrades scaling heavily, especially over long periods or multiple overlapping daily templates.
**Action:** Replace nested query checks with a single initial query outside the loop using `array_flip(PDO::FETCH_COLUMN)` to build an O(1) in-memory look-up map, which completely removes the DB check overhead. Further, wrap multiple inserts into a single transaction (`beginTransaction()`/`commit()`) to avoid individual disk write overheads. Crucially, when templates overlap, be sure to update the local `existing_slots` map right after insertion (`$existing_slots[$slot_datetime] = true`) to avoid inserting duplicates that aren't yet committed.
