# Palette's Journal

## Philosophy
- Users notice the little things
- Accessibility is not optional
- Every interaction should feel smooth
- Good UX is invisible - it just works

## 2023-10-27 - Password Visibility Toggle
**Learning:** Users often struggle with password inputs, especially on mobile. The standard "show/hide" toggle is a critical accessibility feature.
**Action:** Implemented a standard Bootstrap 5 input group pattern with a toggle button. This pattern is robust and accessible.
